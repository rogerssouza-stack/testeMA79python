Sistema de Cadastro de Motores em Python

Documentação técnica de uma aplicação monolítica em memória desenvolvida com foco em lógica estruturada, funções e manipulação de arrays (listas).

Onde foi desenvolvido

Este projeto foi criado durante as aulas de programação no CentroWEG, o centro de formação técnica do SENAI localizado dentro do complexo industrial da WEG, em Jaraguá do Sul, Santa Catarina.

A proposta simula o gerenciamento de catálogo técnico de motores elétricos (como potência em CV, tensão nominal, rotação e modelo) utilizando exclusivamente recursos nativos do Python, sem necessidade de banco de dados externo.

Como o Código Python Funciona

Toda a aplicação foi escrita em um único arquivo (arquitetura monolítica) para facilitar a execução e os testes em terminal. Abaixo está o papel de cada estrutura do script:

Array Principal (motores = [])

Funciona como o armazenamento temporário em memória RAM. Cada posição do array guarda um dicionário representando um motor com ID, modelo, fabricante, potência, tensão, RPM e tipo.

cadastrar_motor()

Solicita os dados ao usuário via terminal, valida valores numéricos com blocos try/except para evitar falhas de digitação e gera um ID sequencial automático.

listar_motores() e buscar_motor()

Percorre o array exibindo os dados formatados em tabela no console ou filtra registros específicos pelo número de ID ou por parte do nome do modelo.

atualizar_motor() e excluir_motor()

Permite alterar especificações de um motor existente (mantendo os dados originais caso o usuário pressione Enter) ou remover o item do array após confirmação.

popular_dados_teste()

Insere automaticamente motores de exemplo (incluindo linhas industriais como W22 IR3 Premium e W21) ao iniciar o script para agilizar a validação das funções.

Menu Interativo (while True)

Mantém o programa em execução contínua exibindo as opções numéricas no terminal até que o operador escolha a opção 0 para encerrar.

Exemplo de Registro no Array

Cada motor cadastrado ocupa uma posição na lista seguindo esta estrutura de chaves e valores:

{
    "id": 1,
    "modelo": "W22 IR3 Premium",
    "fabricante": "WEG",
    "potencia_cv": 5.0,
    "tensao_v": 380,
    "rpm": 1750,
    "tipo": "Trifásico"
}
